# Project Workspace Rules

## Phase Discipline
- Phase 1 (Blueprint): Generate an Implementation Plan artifact before writing code
- Phase 2 (Branch Build): Always build inside a dedicated feature branch or worktree
- Phase 3 (Testing): Run automated tests and browser UI verification via /browser
- Phase 4 (Ship): Format code, commit with conventional prefixes (feat:, fix:, chore:), and trigger deployment preview
